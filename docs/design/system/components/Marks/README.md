A mark is a word in a pill. It says in one word what a thing is, and it is never a bare color and never a blank.

- Absence (`.absent`, dashed `line`, `dim` text): `absent`, `not served`, `no state`, `none`. The consumer provides the word the Spec's section 6 vocabulary gives the case; it never invents one.
- Status (`.status`, with its dot): the agent's or the register's own word, in `ok`, `hold` or `fail`. The hue never carries the fact alone; the word does.
- Backing (`.backing`): `built`, `partly`, `unbuilt`. About the pane, never about the agent.
- Query (`.pill.query`): a clause on Record; beside it a plain `.pill` reading "clear".
- The discontinuity row (`.stream li.mark`) is hatched in `inset` over `panel` with dashed `dim` rules, carries the mark's reason as admin-con or the server wrote it, a sentence naming what was not relayed and why (a record past the relay's bound, a backfill begun inside the file, a file truncated, rewritten or replaced, admin-con reconnected, the link to admin-con lost; `src/link/admin_con.rs`, `src/link/listener.rs`), and sits exactly where the gap is. A replayed row is to be `dim` and carry `replayed` in `hold`; that mark is not yet carried and waits on the listener, which classifies each event as replayed or live against the opening's boundary but serves a window that does not say which.

A zero, a blank cell and an empty string are values and never stand in for an absence.
