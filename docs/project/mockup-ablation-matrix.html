A column is one staged experiment against the parent, and its hypothesis is the row labeled Moved from parent, which is a diff and not a field anyone typed. The header of a ran column is a link to the staged experiment's sweep, the fourth read, where each arm's run is reached by its value, so the matrix never reads below the run row and never presents one arm as the column. A column with a freed seed is a sweep on that one member, its values drawn at authoring and frozen at registration, so it is a distribution, and its score reports the count and the worst ratio rather than a mean, because the envelope is stated over the tail.
