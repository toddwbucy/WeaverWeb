The two directories

builtokwhat the operator lays before pairing

The operator lays the disks before pairing, and the appliance's setup script walks through it: a state disk and a models disk, each mounted at a place the operator chooses. Weaver Web lists and formats no disk.

The state directory holds each agent's directory of its own, named for the agent, with the agent's folder and its home side by side inside it. The models directory holds the models in Hugging Face's layout.

The box reports each directory at the place the operator chose, and the next pane names and judges them.
