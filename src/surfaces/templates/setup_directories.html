The two directories

builtokwhat the operator lays before pairing

The operator lays the disks before pairing, and the appliance's setup script walks through it: a state disk, and a models disk at least 10 GiB larger than the model, each mounted at its default path. Weaver Web lists and formats no disk.

The state directory holds each agent's directory of its own, named for the agent, with the agent's folder and its home side by side inside it. The models directory holds the models in Hugging Face's layout.

The box reports the two directories at their default paths, and the next pane judges them.
