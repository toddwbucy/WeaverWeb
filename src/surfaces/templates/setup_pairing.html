At the appliance

builtokthe appliance's setup
  1. Log in at the appliance's console. At its first console login it shows the setup prompt, and the prompt's one command starts the appliance's setup script.
  2. The script walks you through finishing setup, the disks included, and ends in pairing with Weaver Web.
  3. When the script asks for Weaver Web's address and port, give it the two in the next pane.
  4. The script then shows a short code and Weaver Web's fingerprint, in four rows of four groups. Compare the fingerprint with the one in the waiting box's pane, row by row, then enter the code there.
